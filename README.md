# وليد الديب — Android Cinematic AI Studio

تطبيق أندرويد مستقل تمامًا عن DEEB وDEEB19.

## الهوية التقنية
- Kotlin + Jetpack Compose
- Application ID: `com.walidaldib.cinematic`
- Min SDK: 26
- واجهة عربية واتجاه RTL
- المستودع مخصص لهذا التطبيق فقط.

## الحالة الحالية
الموجود حاليًا هو هيكل أندرويد وواجهة تأسيسية. **محرك توليد الفيديو بالذكاء الاصطناعي لم يُربط بعد، ولم يصدر APK مختبر.** لا تعتبر بطاقات الأدوات الحالية وظائف توليد مكتملة.

## خطة العمل
1. استيراد الصور والفيديو ومعاينتها وإدارة المشاريع محليًا.
2. تقييم محركات مفتوحة المصدر قابلة للتشغيل محليًا على أجهزة أندرويد، وتحديد ما يناسب إمكانيات الهاتف.
3. تنفيذ أدوات تحريك الصور والمؤثرات الممكنة محليًا واختبار الأداء.
4. تقييم إمكانات النص إلى فيديو وإضافة ما يمكن تشغيله فعليًا.
5. بناء APK واختباره وتوثيق الوظائف والقيود قبل تسليمه.

## البناء
يتم بناء نسخة Debug من خلال GitHub Actions. افتح تبويب Actions وشغّل Android CI يدويًا، أو ادفع تحديثًا إلى فرع main. ينتج البناء ملف APK كـ Artifact عند نجاحه.
